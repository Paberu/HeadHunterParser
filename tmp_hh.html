В команду обработки трафика ищем QA инженера по нагрузочному тестированию.

Стек технологий, который мы используем: pytest, allure, docker/podman. А вот так мы тестируем: forti, trex.

Чем предстоит заниматься:

  • Написание скриптов для генератора трафика;
  • Автоматизация тестирования с использованием pytest (Setup/Teardown окружения, проведения тестов, снятие метрик, анализ показателей теста);
  • Доработка CI/CD для нагрузочного тестирования.

Ты нам подходишь, если у тебя есть опыт:

  • в нагрузочном тестировании (хотя бы на уровне проведения простейших тестов, знание какой-либо утилиты для нагрузочного тестирования);
  • автоматизации нагрузочного тестирования;
  • написания автоматизированных тестов, работы с python >3, pytest/unittest, python requests.

Будет плюсом опыт:

  • работы с генераторами трафика (fortitester, ixia, t-rex);
  • работы с Linux;
  • знание устройства сетевых протоколов (ARP, IP, TCP, UDP, HTTP, HTTPS)
  • написания bash скриптов;
  • тестирования NGFW (и любого сетевого оборудования).

Мы знаем, как для тебя важно быть профессионалом в своем деле, поэтому даем возможность прокачать свои скиллы, тестировать новые инструменты и сервисы, и прокачать навыки для достижения результатов.
